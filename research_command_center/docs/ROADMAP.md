# 路线图与扩展建议

## 已完成（v1.0.0）

全部 10 个模块、首页 5 个图表、自动/手动备份与恢复、Excel 导出、PDF 全文检索、文献真实性机制、投稿状态人工确认、生信脚本受控执行（默认关闭）、AI 接口层（Anthropic 官方 SDK + OpenAI 兼容）、离线科研体检、浅色/深色主题、110 个自动化测试。

## 近期（建议优先）

1. **参考文献导入导出**：导入 RIS / BibTeX / EndNote XML / Zotero 导出文件；导出选定文献为 BibTeX / RIS，供 Word 插件使用。导入的条目同样标记“待核实”。
2. **Zotero 本地库只读同步**：读取 `zotero.sqlite`（只读副本）中的条目与 PDF 路径，避免重复整理。
3. **批量在线核实**：对“待核实”文献批量与 Crossref/PubMed 比对，生成差异报告，由用户逐条确认采用。
4. **任务提醒**：启动时与每天固定时间检查逾期/即将到期事项，用系统通知提醒（Windows Toast），不联网。
5. **项目模板**：综述、基础实验、生信分析、临床研究等模板，一键生成里程碑与常规任务（均为可删除的建议，不预填结果）。
6. **ICS 日历导出**：导出 `.ics` 供 Outlook / 手机日历订阅（本地文件）。

## 中期

1. **扫描件 OCR**：对无文本层的 PDF 用本地 Tesseract（`ocrmypdf`）生成文本层副本，副本存放在数据目录，原文件不动。
2. **实验数据快速分析**：对登记的 Excel/CSV（只读）做描述统计与常用检验（t 检验、ANOVA），结果作为“分析结果”附件保存，并标注所用方法。
3. **R/Python 运行环境管理**：为每个分析任务记录 `renv.lock` / `requirements.txt` / 会话信息，提升可复现性。
4. **AI 辅助（在授权范围内）**：
   - 文献笔记结构化（PICO、方法学质量要点），输出标注“待人工确认”；
   - 投稿前检查清单（作者贡献、数据可用性声明、AI 使用声明、图表编号一致性）；
   - 本地模型（Ollama）优先，敏感数据可完全不出本机。
5. **全文检索增强**：中文分词（jieba）+ BM25 排序；按项目 / 年份 / 类型筛选结果。

## 长期

1. **桌面封装**：用 PyInstaller 或 `pywebview` 打包成带窗口的桌面程序（无需单独打开浏览器），或封装为 Windows 安装包。
2. **加密与同步**：数据库静态加密（SQLCipher）；可选的端到端加密备份到用户自己的网盘/NAS（默认关闭）。
3. **多人协作**：实验室共享项目与任务（需迁移到 PostgreSQL + 账户权限），个人数据仍保留在本地。
4. **数据库迁移工具**：引入 Alembic 管理破坏性结构变更（当前的“只增列”自动迁移足以覆盖常规升级）。

## 扩展方式（给开发者）

- 新增字段：在 `rcc/models.py` 中加可空列即可，启动时自动迁移；然后在对应 `services/*.py` 的 `clean_*` 函数中加入校验，在 `views/*.py` 中加入表单项。
- 新增页面：在 `views/` 新建文件，并在 `app.py` 的 `pages` 字典中注册。
- 新增模型供应商：在 `rcc/services/ai/providers.py` 中实现一个函数并加入 `chat()` 分派；在 `profiles.PRESETS` 中加入预设。
- 所有写操作都应经过 `services` 层，并调用 `crud.log_activity` 留痕；任何会修改文件、执行代码的功能都必须先展示内容并由用户确认。

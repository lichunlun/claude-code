## 4. 测试中发现并已修复的问题

| 问题 | 修复 |
|---|---|
| 实验参数表中的空单元格被 pandas 转成 NaN，保存成了文字 “nan” | 统一的空值判断 `is_null()`，NaN / NA / NaT 视为空 |
| 外键错误在部分写入路径上以原始数据库异常出现 | 在会话层统一转换为中文校验提示 |
| 冷启动时对话框表单可能被重复提交（项目被唯一约束拦下，但任务等没有唯一字段的记录可能重复） | 所有新建表单加入防重复提交；新建项目后的跳转移出对话框 |
| Streamlit 顶部栏遮挡页面第一个元素（“返回项目列表”按钮） | 调整页面上边距 |
| 表格空值显示为 “None” | 统一显示为 “—” |
| 日历中已逾期事项未显示为红色 | 日历视图对未完成且已过期的截止类事项标红 |
| 首页指标卡高度不一致；截止日期列表过长 | 固定卡片高度；列表限 6 条并截断过长的项目名 |
| 任务状态多选框显示不全 | 改为“药丸”多选 |
| 页面内说明的深色模式入口有误（Streamlit 1.66 改为菜单中的 Light/Dark/System） | 更正说明 |

## 5. 已知限制（如实记录）

1. **未在 Windows 实机上运行**。本次开发环境为 Linux 容器。为 Windows 做了以下处理：`.bat` 使用 CRLF 换行且只含 ASCII；路径统一用 `pathlib`；SQLite URI 用 `Path.as_uri()`（正确处理盘符和中文路径）；打开文件用 `os.startfile`；关闭进程用 `taskkill /T`。首次在 Windows 上运行时，如有问题请把命令行窗口的输出发给我。
2. **Crossref / PubMed 在线比对**：本环境的网络策略拦截了这两个站点，因此只用模拟数据验证了解析逻辑与网络失败时的提示；在您的电脑上联网即可使用。
3. **AI 调用**：未配置任何真实 API Key，Anthropic 与 OpenAI 兼容接口均以模拟方式测试了请求构造、错误处理与留痕。首次真实使用时可点“测试连接”。
4. **R 脚本执行**：本环境未安装 R，只实际执行了 Python 脚本；R 脚本走同一条代码路径（`Rscript 脚本 参数`）。
5. 访问子页面 URL 时浏览器控制台会出现 Streamlit 自身的 `/<页面>/_stcore/health` 404 探测请求，这是 Streamlit 的路径探测行为，不影响使用。
6. 扫描版 PDF 没有文本层时无法建立全文索引（导入时会提示），OCR 列入路线图。

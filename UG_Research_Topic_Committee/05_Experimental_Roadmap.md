## 1. 开工前必须先解决的五件事

这五件事不解决就开始做实验，是本科生科研失败最常见的原因。**它们合计约需 2–3 周，但能省掉几个月。**

| # | 事项 | 为什么必须先做 | 判定标准 |
|---|---|---|---|
| 1 | **读 2013 年原文全文**（PMID 25206424） | 方案 A 全部建立在重复它之上。若其分化方案参数未写全，你要先摸条件——这本身是一个发现，但也是一个延期 | 能抄出：传代数、血清种类与浓度、分化诱导剂与浓度、分化天数、铺板密度、谷氨酸浓度与处理时长 |
| 2 | **确认酶标仪能力** | resazurin 需荧光；若只有吸光度，设计要砍一条读数臂 | 书面确认：是否有荧光模块？激发/发射波长可选范围？是否有发光（luminescence）模块？ |
| 3 | **确认 HT-22 来源与传代数** | HT-22 的表型随传代漂移；高代数细胞分化能力下降 | 记录供应来源、到手时的代数、冻存批次。**全研究使用同一批冻存，代数差不超过 5** |
| 4 | **核实 GluN1/GluN2B 抗体** | 若抗体在 HT-22 中给不出可信条带，Fig 1 的蛋白臂落空 | 找到至少一个在**小鼠**样本中有发表数据的克隆号；准备小鼠脑裂解液作阳性对照 |
| 5 | **去问电生理平台** | 膜片钳是受体功能的金标准。一次询问可能把论文天花板抬高一整档 | 明确回答：能否借用？是否需合作署名？排期多久？ |

> **第 5 项的现实提醒**：即使答案是"不能"，你也必须在论文 Limitations 里主动写明
> "本研究未进行电生理记录，因此受体层面的结论基于转录本/蛋白表达与药理学，不基于电流"。
> 主动承认比被审稿人指出要好得多。

**路线设计的三个要点**

1. **轴线二先做**。它最便宜（几百元）、最快（1 周）、且不依赖细胞状态。
   第 1 周就能知道这条轴线是否存在。
2. **"同一批孔，四种读数"是本研究不可妥协的核心**。
   若分批测量，读数差异可被批次差异解释，整个设计失去意义。
   实操上：同一块 96 孔板，先做非破坏性读数（resazurin 可在活细胞中孵育后换液），
   LDH 取上清，CCK-8/MTT 最后做——**顺序必须在阶段一确定并固定下来，并在论文中报告**。
3. **因果臂（siRNA）放在阶段二后半**，因为它依赖阶段二前半证实受体表达存在。
   若受体表达为阴性，这一臂自动取消，而论文仍成立（变成"分化并未带来受体表达"）。

## 3. 阶段一停止标准（第 8 周，必须书面判定并签字留档）

| 判定 | 条件 | 行动 |
|---|---|---|
| ✅ **继续** | 分化方案可重复（≥2/3 次），且分化/未分化谷氨酸 EC50 的 95% CI **不重叠** | 进入阶段二，全速 |
| ⚠️ **继续但转向** | 分化方案可重复，但两者 EC50 的 CI **重叠** | **这本身是阴性结果，有发表价值**。继续，论文重心转为"未能重复 2013 年"，强化轴线二 |
| ⚠️ **轴线二削弱** | 无细胞矩阵显示所有化合物对所有读数均无干扰（且抗坏血酸阳性干扰对照成立） | 保留轴线一主干，轴线二降为补充图，诚实报告阴性 |
| ❌ **停止** | 分化方案 3 次独立尝试均失败 | **转 C02 单做**（只做检测审计，4–6 个月，见 `02` C02 条目） |
| ❌ **停止** | 抗坏血酸阳性干扰对照**不成立**（即体系检不出已知干扰） | 无细胞体系有问题，先修体系，不要推进 |

> **为什么要签字留档**：预先写下停止标准并执行，是"预注册"的最低成本版本。
> 它在审稿时的价值，大于任何一个额外实验。

### 4.1 考研时间冲突的处理

**第 5–6 月的主线负荷最可压缩**——文献审计不需要细胞、不怕中断、可以在图书馆做。

若冲突严重，两个方案：

- **方案甲（推荐）**：把 siRNA 主实验从第 6 月推到第 7 月，总周期延至 **11 个月**。
  代价小，因为 siRNA 臂不是论文的承重墙（Fig 5 才是）。
- **方案乙**：第 5–6 月完全停止湿实验，只做文献审计 + 公共数据。
  总周期延至 **12 个月**。这仍在你设定的范围内。

**不要做的事**：不要在冲刺期勉强跑 siRNA。转染失败率高、重复成本大，
一次失败会吃掉两周，心理负担远超时间成本。

### 7.2 分析脚本的设计要点

`analyze_assay_matrix` 做三件你手算容易出错的事：

1. **强制把"交互项"作为主要输出**，而不是主效应。
   方案 A 的核心主张是"效应量随读数改变"，所以 `干预 × 读数` 的交互项就是结果本身。
2. **强制报告效应量与 95% CI，而不只是 P 值**。
   脚本在只报 P 值时会打印警告。
3. **无细胞干扰校正**：用无细胞矩阵测得的显色剂还原量，
   对细胞内读数做校正，并输出"校正前 vs 校正后"的表观保护率差值——**这就是 Figure 5 的数字**。

### 7.3 运行方式

```bash
python3 code/analyze_assay_matrix.py --selftest
```

```bash
python3 code/analyze_assay_matrix.py data/assay_matrix.csv
```

```bash
Rscript code/analyze_assay_matrix.R data/assay_matrix.csv
```

### 7.4 数据录入格式

脚本要求一个长格式 CSV，每行一个孔：

| 列 | 含义 | 取值 |
|---|---|---|
| `experiment` | 独立实验编号（= 生物学重复） | exp1, exp2, … |
| `plate` | 板号 | |
| `well` | 孔位 | A1 … H12 |
| `differentiation` | 分化态 | `undiff` / `diff` |
| `treatment` | 干预 | `vehicle` / `MK801` / `memantine` / `DTT` / `Fer1` |
| `glutamate_mM` | 谷氨酸浓度 | 数值，0 表示无 |
| `readout` | 读数方法 | `CCK8` / `MTT` / `resazurin` / `LDH` |
| `raw_value` | 原始读数 | 数值 |
| `cellfree` | 是否无细胞对照孔 | `TRUE` / `FALSE` |

> **录入纪律**：`experiment` 列是生物学重复的唯一依据。
> **同一天同一板的复孔不是生物学重复**，必须共用同一个 `experiment` 值。
> 脚本会在 n 的计算中按 `experiment` 聚合，并在技术复孔被误当作 n 时报错。

## 9. 一句话总结路线

> **第 1 周做一个不含细胞的实验（几百元），它会告诉你这个课题的一半是否存在。
